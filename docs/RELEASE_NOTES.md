# SAGA main-method release

## Reference and scope

This package isolates the current main attack from `Review-Generation-Attack`
commit `ca57421e23ba12da13df54db330c9330730e19c4`. The original source snapshot was
verified against that Git commit. The input images and caption files are unchanged.

The supplied command uses Qwen3-VL layer 29 generation-time attention, fixed clean
attention maps, progressive SAGA region selection and B16/B32/Laion optimization.
Baselines, ablations, EOT, dynamic/teacher-forced attention, evaluation APIs and
remote logging are excluded.

## Preserved execution behavior

- Generation attention, causal-row indexing, content filtering and normalization.
- Rectangle ranking, area tolerance, IoU fallback, coordinates and schedule order.
- Contiguous CHW inputs, crop RNG/interpolation, surrogate encoders/objective,
  sign-gradient ascent and perturbation projection.
- Original seed 43 initialization followed by model-initializer seed 2023 reset.
- Effective hotspot probability 1.0 and final-schedule-item update remainder.
- Original subset sampling from directory enumeration before selected-ID sorting.
- Qwen automatic device placement and inputs on the model's input device.

The optimizer uses no-grad `copy_` in place of assigning `.data`; the regression
and actual-model comparisons are documented in `VALIDATION.md`.

## Release interfaces

Modules are organized under `saga/`; `python -m attack` remains the entry point.
The main command and hyperparameters are explicit in `scripts/run_saga.sh`.

Input pairing fails early for malformed/missing/duplicate IDs. Outputs use source
IDs instead of caption-derived paths, and include only `original.png`,
`adversarial.png` and `metadata.json`. The saved clean PNG is the resized optimizer reference.
Existing outputs require explicit `--resume`; this does not restore the sequential
RNG stream. Use a fresh output for strict comparisons.

The lockfile defines the tested release environment, not a recovered historical
paper environment. The `.python-version` file selects Python 3.12. The scope and
results of CPU and GPU comparisons, including model revisions and source hashes,
are in `VALIDATION.md` and `docs/validation/`.

## Distribution

The ZIP includes 1,000 clean AADCD inputs for the server test; Git ignores them.
Model weights and virtual environments are not included. `attacked_images/` includes
1,000 historical PNGs from `260120_aadcd_ours_qwen3vl_seed43`, their per-image target
README and exact JSONL mapping. They were copied unchanged, not regenerated by
the cleaned code. Clean-image identity and target-directory correspondence were
verified for all 1,000 pairs.
No publication, commit or push was performed. No new license terms were assigned
to the research code or dataset.

## Public output simplification (2026-09-28)

New attack runs save only `original.png`, `adversarial.png`, and `metadata.json`
per sample. Metadata contains settings, environment, source/image hashes and
completion state for resume. Existing trace-rich runs require a new output name;
previously saved files are not removed. Optimization and attention calculations
are unchanged.
